| Option | What you add | You should see | Guide |
| --- | --- | --- | --- |
| Quiz mode | One rule in `your_code/prompts.py` | A 3-question quiz on what you studied, with a score | [quiz_mode.md](quiz_mode.md) |
| A second tool | One word in `your_code/tools.py`, one rule in `your_code/prompts.py` | The agent choosing between Wikipedia and web search, and saying why | [second_tool.md](second_tool.md) |
| A web page | Nothing - just run it | Study Buddy in a browser chat window | [web_page/README.md](web_page/README.md) |
